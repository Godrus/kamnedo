# Камнедол

Крепость, которую ведут пальцем. Копайте залы в горе, кормите дворфов, жгите факелы и не проспите шорох в глубине. Одинаково на телефоне и на компьютере.

## Запуск

```bash
npm install
npm run dev
```

Игра открывается на [http://localhost:8080](http://localhost:8080).

## Управление

- Зажмите склон и ведите — так ставят копку.
- Два пальца крутят гору. На компьютере — мышь, WASD и клавиши 1–9.
- Слой режет гору как чертёж, объём показывает залы целиком.
